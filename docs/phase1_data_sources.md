# Phase 1 Data Sources

Raw datasets are intentionally not included.

## Source 1

File:

`data/raw/car_listings/Australian Vehicle Prices.csv`

## Source 2

Add one or more Green Vehicle Guide CSV exports under:

`data/raw/vehicle_specs/`

## Source 3

Add the Australian postcode/locality CSV as:

`data/raw/locations/australian_postcodes.csv`

Expected useful columns include:

`locality, state, postcode, latitude, longitude`

## Optional Source 4

RBA / ABS data goes under:

`data/raw/economic/`

Only use if the primary listing dataset has a reliable observation/listing date.
